# Рустам Гасымов — портфолио

Личный сайт: Python backend и AI-системы.

Проекты разложены как карты на столе: страница проваливается в маленькую 3D-комнату в духе PS1 (лампа, свеча, крупье напротив), каждая сыгранная карта открывает разбор проекта.

## Устройство

- `index.html` — вся страница: разметка, стили, данные проектов, разборы, пасьянс.
- `table.js` — 3D-сцена стола на three.js (рендер в низком разрешении, дизеринг, пиксельные карты).
- `shots/` — скриншоты для превью проектов.

Сборки нет: это статический сайт, three.js и шрифты подключаются с CDN.

## Локально

```bash
python3 -m http.server 5173
```

и открыть http://localhost:5173 (через `file://` модуль `table.js` не загрузится).
